# Sistema Integrado Sulnet V1 — v68h-troca-titular

Versão baseada na v68g, adicionando os campos específicos da categoria TROCA DE TITULAR.

## Regra de exibição

Após selecionar:
- Categoria: TROCA DE TITULAR
- Produto/plano da categoria

O formulário da oportunidade abre automaticamente o bloco:
"Informações do produto — Troca de Titular".

## Campos incluídos

### Atual titular
- Atual titular
- Plano atual
- Valor
- Número do contrato a ser transferido
- Cód. conexão

### Novo titular
- Novo titular
- Plano
- Valor
- Data de vencimento
- Cód. da nova conexão
- Unificar as faturas: Sim/Não
- Troca de equipamento: Sim/Não

### Equipamento / instalação
- Retirar
- Instalar
- Disponibilidade do cliente
- Rede WiFi
- Senha
- Contato do cliente

### Caso for empresa
- Sócio(a) administrador(a)
- CPF do sócio(a)

### Documentos obrigatórios
- Documento com foto
- Selfie com documento
- Print da conversa com aceite

## Funcionalidades preservadas

A v68h preserva:
- chat;
- filas;
- grupos;
- Z-API;
- webhook;
- layout visual Sulnet;
- campos da categoria Fibra;
- campos da categoria WIFI Adicional.
