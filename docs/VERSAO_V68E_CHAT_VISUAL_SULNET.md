# Sistema Integrado Sulnet V1 — v68e-chat-visual

Versão baseada na v68d, com ajuste visual do Chat Operacional.

## Alteração principal

Aplicado tema moderno com identidade Sulnet:

- Branco como base;
- Laranja Sulnet como cor de ação/destaque;
- Preto e cinza para textos/estrutura;
- Interface mais limpa e agradável;
- Menos contraste escuro no chat;
- Mensagens, lista, cabeçalho, composer, painel lateral e modais ajustados.

## Funcionalidades preservadas

Nada foi alterado nas regras de:
- filas;
- grupos;
- usuários;
- Z-API;
- webhook;
- envio de texto;
- envio de mídia;
- abertura de atendimento por fila.
